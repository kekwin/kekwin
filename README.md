# Hej, jeg hedder Kewin 👋

Til dagligt arbejder jeg hos **MentorDanmark**. Om aftenen bygger jeg små værktøjer til mig selv og familien: styr på økonomi, indkøb, opskrifter, skraldedage og alt det andet, der ellers ender i et regneark.

## Det jeg roder med lige nu

- 🏠 En hjemmeserver med små apps til familien: økonomi, indkøbsliste med prisovervågning, opskrifter og projekter i huset
- 🤖 MCP-servere, så AI-assistenter kan hjælpe med de samme ting, fx [aula-mcp](https://github.com/Casperjuel/aula-mcp), som jeg har bidraget til
- 🏸 Småting, der gør offentlige systemer mere brugbare, fx et [brugerscript til Book Byen](https://github.com/kekwin/bookbyen-userscript)
